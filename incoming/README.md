# Загрузка утверждённых игровых кадров

Чтобы автоматически внедрить золотую броню, загрузите в эту папку файл **approved_knight.zip** (внутри ровно 12 PNG по 279×370: attack_01–06, hurt_01–06). В архиве файлы лежат в `assets/costumes/approved_knight/`.

GitHub Actions «Install approved knight costume» автоматически извлекает кадры, заменяет ими старую графику `steel_knight`, сохраняет цену **50 монет**, оригинальный ID купленного предмета, отдельный SVG-меч, проверяет `npm test` и пушит результат в `main`.

Оригинальный котёнок и «Лесной страж» не изменяются.
