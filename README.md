# Храбролап: Тихая пристань — v0.9.2

Продолжение пользовательской v0.9.1: котёнок развёрнут вправо, ведро слева от рыцаря, убраны дубли ведра и лески, подключены восемь новых SVG-моделей монстров. Кнопка «Автобой» включает ручной бой с отдельной кнопкой «Удар»; выбранный режим сохраняется.

Три вида атак, 18 поз, сменные SVG-мечи и броня сохранены. Баланс автобоя не менялся. Рыбак остаётся человеком-рыцарем из утверждённой фоновой иллюстрации.

## Запуск

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

Открыть `http://127.0.0.1:8080/` в браузере. Игра использует ES-модули и требует HTTP.

## Проверки

```sh
npm install
npm test
npm run qa:balance
npx playwright install chromium
npm run qa:browser
```

`qa:browser` требует запущенного HTTP-сервера. GitHub Actions запускает его автоматически и сохраняет реальные скриншоты в артефакте `hrabrolap-qa`.

Текущий отчёт: [QA-v0.9.2.md](QA-v0.9.2.md). Локальные проверки прошли. Браузерный прогон NOT RUN: локальный Chromium не установился, отправка ветки для CI требует явного согласия пользователя после отказа автоматической проверки разрешений. История прежних результатов и ограничений сохранена в `docs/README-v0.9.1-history.md`.
