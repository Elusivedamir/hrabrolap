## Причина блокировки браузера

1. Попытка запустить установленный Playwright 1.62.1 завершилась ошибкой: исполняемого `chromium_headless_shell-1234/chrome-headless-shell-linux64/chrome-headless-shell` нет.
2. Доступный облачный Chrome при открытии `http://127.0.0.1:8080/` вернул `net::ERR_BLOCKED_BY_CLIENT`.
3. Открытие синхронизированной копии через `file://` отклонено URL-политикой браузера: разрешены только HTTP/HTTPS. Обходы этой политики не выполнялись.
4. Рассмотрен поддерживаемый стенд Sites. В этой управляемой среде он требует отсутствующий control-browser; Site не создавался, внешняя публикация не выполнялась.

Поэтому нельзя утверждать, что игру удалось фактически запустить на мобильном экране. Подключённый браузер сам по себе не даёт доступа к локальному серверу другой среды.

Разрешённый путь продолжения: выполнить подготовленный прогон в GitHub Actions либо на рабочей машине разработчика, где доступны Chromium и локальный HTTP. В ZIP включены `.github/workflows/qa.yml` и `tests/browser.test.mjs`. Они создают мобильный контекст 390×844 с touch, проверяют интерфейс и сохраняют настоящие скриншоты. Их выполнение здесь **NOT RUN**; подтверждён только синтаксис браузерного теста. Установка и запуск в этой сессии не маскируются как выполненные. Просмотр скриншотов и устранение выявленных браузерных проблем остаются обязанностью разработчика.

## Баланс 100 волн

Исполнялся настоящий `stepFight` с шагом 0,1 игровой секунды. Ускорено вычисление шагов, не параметры игры. Начало с нулём монет, без подаренных уровней/урона/HP и без принудительных побед. Покупается только доступное за заработанное; контрольные сценарии ограничены 10 800 игровыми секундами. Коэффициенты v0.8 не менялись.

В сбалансированной стратегии выбирается более дешёвый из апгрейдов меча/HP, максимум одна покупка на решение. В стратегии с экипировкой новые мечи/броня участвуют в том же выборе по цене; рыба продаётся при каждом визите. Это идеальное поведение тестового покупателя, не оценка среднего игрока. Рыба генерируется детерминированным PRNG с указанным seed; сеть, частота кадров и затраты времени пользователя не моделируются.

Наблюдения для игровой приёмки: без покупок продвижение остановилось перед 10-м боссом; односторонние улучшения сильно задерживают главу; экипировка вместе с продажей рыбы примерно вдвое сокращает расчётное время. Сбалансированное прохождение всё равно включает 24–79 поражений в зависимости от стратегии. Это может требовать обсуждения темпа игры; автоматически менять цены, силу врагов, лечение или награды по этим данным не стал.

## Неизменность художественной части

SHA-256 проверены для всех 59 файлов `art/`, `assets/` и `art-proof-v07.jpg`. Совпадают исходные изображения котёнка и рыцаря, все монстры, мечи, броня, корона, фоны, исторические шесть кадров удара. `style.css` и массив `ATTACKS` также неизменны. В HTML обновлён только номер версии. Поэтому существующие художественные ограничения v0.8 остаются; данная сборка не утверждает внешний вид прототипов.

## Дальнейшая работа

Процесс после каждого изменения закреплён в `AGENTS.md`: логика → симуляция → настоящий мобильный браузер → просмотр скриншотов → отчёт и ZIP. Полный `npm run qa` включает браузер и не должен считаться успешным без него. Подготовленный CI не запущен и не является доказательством выполненной проверки. Пользователю не передаётся обязанность технического тестирования; от него требуется утверждение художественных и игровых решений.
