# 10 отдельных SVG-комплектов

Этап согласования дизайна. Комплекты не подключены к котёнку и анимации. Прежние игровые слои не изменены.

В каждом прозрачном SVG 360×440 семь редактируемых групп: `helmet`, `collar`, `torso`, `leftSleeve`, `rightSleeve`, `leftBoot`, `rightBoot`. Это позволяет отдельно подгонять части под позы. Их нынешнее расположение — раскладка комплекта для просмотра, а не координаты будущего рига.

| Файл | Комплект | Конструкция |
| --- | --- | --- |
| web.svg | Паутинный ткач | Стёганый кафтан, тканевые рукава, плетение и фестоны |
| steel.svg | Рыцарский панцирь | Кольчужная рубаха, кираса, наплечники и поясные пластины |
| bone_slime.svg | Кость и слизь | Мягкая органическая куртка с костяными рёбрами |
| chitin.svg | Хитиновый страж | Высокий ворот, надкрылья, перекрывающиеся сегменты |
| leaf.svg | Лесной разведчик | Туника и рукава из листьев с прожилками |
| moss.svg | Мшистый хранитель | Гибкие полосы коры, разные плечи, мшистая опушка |
| shadow.svg | Теневой странник | Кожаная куртка с запахом, перевязи и разрезной подол |
| moon_armor.svg | Лунный дозор | Длинное облачение, серебряные дуги и разные наплечники |
| star.svg | Звёздный паладин | Чешуйчатая основа, лучевые плечи, многослойный подол |
| king.svg | Королевский доспех | Красный кафтан, золотая кираса, пелерина и набедренники |

Все части — векторные path/ellipse/circle, без встроенных картинок, скриптов и внешних ресурсов. Названия ID соответствуют существующему каталогу; игровые характеристики не изменяются.

Генерация: `node tools/build_armor_designs.mjs`. Галерея проекта: `armor-design-review.html`. Проверка реального Chromium: `npm run qa:armor-designs` при запущенном HTTP-сервере. Следующий этап — художественная приёмка, затем отдельная подгонка под утверждённые кадры.
