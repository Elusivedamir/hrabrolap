# Очистка контуров Forest Guardian · версия 3

После проверки мобильных кадров сняты дублирующиеся линии около мордочки и открытых кулаков, а также уменьшены паразитные края вокруг ботинок и листовой юбки. Новые 12 прозрачных PNG подготовлены отдельно в `forest_guardian_cleaned.zip`: один файл на каждый канонический кадр (279×370, RGBA). Исходные файлы котёнка **не менялись**. Алгоритм использует отбор зелёных, золотых и красных деталей доспеха, семантическую сегментацию и лёгкое сглаживание края — не пересоздаёт котёнка.

Для установки: скачать архив, развернуть в корне репозитория и отправить в main файлы из `assets/armor/forest_guardian/` через Termux. Новая метка `?fit=3` предотвращает подгрузку старых изображений из кэша браузера после установки.

Статус: автоматическая проверка 12 изображений по размерам/альфа-каналу пройдена локально. Реальная мобильная художественная проверка **после** установки архивных PNG ещё требуется: на отдельных контурах возможны мелкие артефакты. Не заявлять финальный PASS без неё.

# Покадровая перекалибровка «Лесного стража» (17.10.2026)

Найдена причина разъезда: прежние PNG были уменьшены общим коэффициентом 0,70 и манжеты не совпадали с лапами. Дополнительно крупные овальные клипы повторно рисовали участки оригинального котёнка поверх костюма.

**Исправление:** 12 новых прозрачных PNG `forest_guardian_corrected.zip` получены из ранее утверждённого полнофигурного референса «Лесной страж», зарегистрированы **по соответствующим** оригинальным позам. Сопоставление референса с исходными листами выполнено SIFT с RANSAC; во всех 12 случаях получены устойчивые совпадения лица и лап с преобразованием около scale=1.16, x=-1, y=+15 в системе оригинального кадра 279×370. По зарегистрированному изображению выделены именно изменённые пиксели брони; лапы, мордочка и исходные кадры не изменяются.

**Игра:** теперь рендерит базовый PNG котёнка + прозрачный PNG брони (без повторной овальной копии кота) + SVG-меч. Те же слои используются в мобильном предпросмотре.

**Ограничение:** исправленные изображения создавались из утверждённого референса и проверены на локальном композите с исходными полными листами, но пока ещё не установлены в GitHub. Для завершения заменить 12 PNG в `assets/armor/forest_guardian/` архивом из чата и отправить коммит через Termux. Затем проверить в реальном мобильном Chromium и не утверждать художественный PASS без просмотра финального рендера.

# Лесной страж · покадровое внедрение

Этот коммит добавляет **отдельную** броню `forest_guardian` за 50 монет, не меняя оригинальные кадры и остальные комплекты.

- Новый рендер: 12 индивидуальных PNG кадров `assets/armor/forest_guardian/forest_{attack,hurt}_0X.png` поверх оригинального котёнка; маска возвращает исходные пиксели мордочки и лап поверх доспехов.
- Отдельная страница предпросмотра `forest-guardian-preview.html` с включением/выключением брони.
- Логика покупки/инвентаря использует существующий формат сохранения v4; здоровье нового костюма +0.
- Художественный исходник: присланный пользователем зелёный доспех с красным платком, а не `art/armor-designs/leaf.svg`.

**Критично:** при коммите исходные изображения из ChatGPT ещё не загружены в GitHub, поскольку коннектор GitHub принимает текст, но не байтовую копию присланного файла. Они поставляются отдельным ZIP. Перед игровым запуском нужно распаковать `forest_guardian_sprites.zip` в корень репозитория и загрузить PNG в `main` через Termux. До этого в магазине возможна пустая миниатюра нового предмета и отсутствие слоя.

Сверка графики по приложенному листу: предварительное наложение произведено на исходные листы изображения котёнка, НЕ на реальные PNG в браузере. Расстановка деталей рукавов пока требует художественной проверки; полный PASS не заявлен.

Следующий QA: `npm test`, `npm run qa:balance`, `npm run qa:browser`, осмотр 12 кадров в `forest-guardian-preview.html` на телефоне 390×844, затем коррекция посадки вручную при необходимости.
