# Примерка посадки брони

Изображения ниже получены из работающего Chromium, а не из генератора картинок. Сам котёнок использует прежние утверждённые PNG. Векторная броня накладывается отдельно.

## Новый крой одного рыцарского комплекта

Прежняя посадка на животе отклонена. Рыцарский комплект теперь имеет цельную основу от плеч до пояса, рукава и боковины. Шлем и обувь скрыты только в примерке для оценки кроя. Остальные девять ещё не переделаны по этому подходу.
