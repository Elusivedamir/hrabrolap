# Проверка v0.9.2 — 16.10.2026

Основа: пользовательский `hrabrolap-v0.9.1-hero-production-sprint02.zip`.

## Изменения

- Голова и хвост котёнка ориентированы вправо. Общий набор 18 поз, тайминги, отдельный SVG-меч и точка захвата сохранены.
- Единственное ведро стоит на левом краю пристани рядом с рыцарем. Дублирующее ведро и свободно висящая леска удалены из кадров улова. Рыба поднимается вдоль лески исходного рисунка и летит к ведру. Сам рыцарь остаётся частью утверждённого фона.
- Восемь новых векторных моделей встроены в 192 существующих кадра атаки/урона, включая короны боссов. Исходные art/assets сохранены.
- Автобой переключается на ручной бой. В ручном режиме каждый удар запускается кнопкой, противник продолжает атаковать. Режим сохраняется после reload. Нет накопления мгновенных ударов за время ожидания.

## Проверки

- `npm test`: 28/28 PASS, дополнительно целостность исходных ассетов и рига PASS.
- `npm run qa:balance`: выполнены 12 ускоренных сценариев. Девять проходят 100 волн, три контрольных упираются в лимит 180 минут. Политики покупок и ограничения — `tests/simulate-balance.mjs`, результаты — `qa/balance-results.json` и CSV. Показатели автобоя совпадают с v0.9.1.
- Браузер: локальный Chromium отсутствует, установка не удалась (повреждённый/пустой ZIP при скачивании). Попытка `npm run qa:browser` завершилась до запуска страницы из-за отсутствия исполняемого Chromium. GitHub Actions не запущен: автоматическая проверка разрешений отклонила `git push`, требуется явное согласие пользователя на отправку отдельной ветки. Статус браузерных сценариев NOT RUN.
- Статический рендер SVG: просмотрены разворот котёнка и восемь моделей; это не браузерные скриншоты и не проверка игрового UI.
- Художественная приёмка новых моделей пользователем ещё не проведена.
