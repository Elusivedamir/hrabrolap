# История изменений

## 2026-11-10 — v0.5c-archive-review-r1: преемственность, аналоги и защита
- Проверен отдельно ранний 23-тельный архив, который НЕ заменяет позднюю документированную 24-тельную v0.5c; его SHA-256 и исходный GitHub HEAD зафиксированы в cad/archive_review_v05c_r1/provenance.json. Сохранены исторические генератор и отчёты; пути зависимостей исправлены на структуру GitHub.
- Проверены OpenHand, Prosthetic-Hands, Brunel, HACKberry; сравнение и снимки коммитов — docs/ANALOGUES_v05c.md. Сторонние конструкции не копировались.
- Строгий тест всех пар обнаружил 13 пересечений осей с кривошипами в 7 позах. Добавлены сквозные отверстия 3,2 мм, оси продлены до 8 мм. Осевое удержание/шайбы ещё не разработаны.
- У 6 повернутых thumb_prox выявлена некорректная BRep в CadQuery 2.7.0. В v0.5c заменено общее преобразование геометрии на жёсткое вращение/перенос с сохранением аналитических поверхностей.
- Повторный аудит: 23 корректных тела, каждое с одним solid в каждой из 7 поз; 1771 парная проверка (210 точных булевых пересечений после AABB), 0 неклассифицированных пересечений. 7 случаев перекрытия ротора с фалангой сохранены как нерешённый интерфейс; это НЕ успешная сборочная проверка всего протеза.
- Исправлена ось вращения проксимальной фаланги в анимации: B+6A вместо B. Реальные матрицы акторов сверены с CAD: 56 ориентиров/7 поз, максимальная ошибка около 1,59e-14 мм. Времена фаз приведены к 1,5 с как программной цели.
- MP4 в текущем окружении не сгенерирован: VTK сообщил bad X server connection (DISPLAY отсутствует). Отдельный Agg-рендер используется для статических CAD-превью; старое видео не выдаётся за исправленное.
- Пыле-/влагозащита переведена в перечень конкретных интерфейсов и резервов; рассчитан пример стыка с прокладкой. Это отдельный CAD-образец, а не защищённый корпус кисти. Обнаружены нехватка места для уплотнения CMC и выступ неподвижного моста за предварительный габарит ладони.
- MG90S остаётся кандидатом для макета противопоставления. Паспортный stall не является рабочим моментом; отдельный привод сгибания, крепления, аварийный сброс, 8 хватов, 10 кг, FEA, ЭМГ и IP не проверены.

## 2026-11-10 — CAD v0.5c: электропривод CMC большого пальца
- Устранён ручной установочный поворот: добавлен серийный кандидат MG90S 180° и связь 1:1 через 2 кривошипа радиусом 14,5 мм и тягу 49,820 мм.
- Отдельные модели двигателя, прижимной PETG-рамки, опорной металлической пластины, ротора Ø8, вилочного крепления, штифтов и тяг.
- Для крепления привода и опоры введены 4 отверстия М3 в концептуальный каркас. Нет FEA, детальная прочность не подтверждена.
- Установлена реальная геометрия осевого пальца MCP Ø3, для будущего независимого сгибания.
- В итерациях обнаружены и устранены пересечения корпуса привода с держателем, опоры с ротором, тяги с большим пальцем, вилки с его основанием.
- CAD: 24 валидных тела; 7 выбранных поз, 83 OCC BRep-проверки, 0 проникновений среди этих пар. Видео 9,5 сек.
- В GitHub опубликованы параметры и отчёт, но локальные Python/STEP/GLB/MP4/ZIP пока нужно перенести.
- Безопасность на теле, электромиография, испытание 10 кг, рабочее усилие сервопривода и физический прототип НЕ подтверждены.
