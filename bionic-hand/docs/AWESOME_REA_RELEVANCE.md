# Источник Awesome-REA: пригодность для нашего DIY-протеза

Проверено 2026-11-10. [reacher-z/Awesome-REA](https://github.com/reacher-z/Awesome-REA), README blob SHA `1c66009a729fadfe9433abdb8b7f8c0c945b0266`.

**Это кураторский каталог обратной инженерии** приложений, прошивок, бинарных файлов и протоколов, НЕ CAD/CAE-библиотека, НЕ библиотека исходников готового протеза и НЕ программа для автоматического расчёта шарниров. Источник не встраивался в текущую CAD-модель: для механики используем CadQuery/FreeCAD и верифицируемую математику.

Подходит для будущих задач электроники:
- [PulseView / sigrok](https://github.com/sigrokproject/pulseview) — осциллограммы логических/аналоговых каналов совместимых измерителей при отладке **изолированного стенда** без электродов на коже.
- [OpenOCD](https://github.com/openocd-org/openocd) — SWD/JTAG отладка **совместимого** выбранного микроконтроллера, если такая необходимость возникнет.
- [Binwalk](https://github.com/ReFirmLabs/binwalk) — разбор образа прошивки законно полученного мотора/контроллера, **только при реальной проблеме совместимости**.
- [Wireshark](https://gitlab.com/wireshark/wireshark) — анализ собственного Bluetooth/сетевого обмена, если появится беспроводная диагностика.

**Не используем сейчас** Ghidra/EMBA/Binwalk просто ради сложности: для самодельной кисти нам нужны рыночные датчики/контроллеры с открытой документацией, а не анализ чужой закрытой прошивки. По мастер-промту v4.2 приоритет безопасности, простоты, цены. ЭМГ на коже использовать только с безопасной, проверенной электрически изолированной системой после профессиональной оценки. Никаких несанкционированных средств обхода защит или прошивки чужих изделий.

Если появится конкретная плата и реальный лог связи — инструмент выбирается по измеряемой задаче, с фиксацией версии, аппаратного интерфейса, тестов и доказанного результата.
