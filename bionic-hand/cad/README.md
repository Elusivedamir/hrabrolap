## Перед продолжением v0.5
1. Загрузить недостающие двоичные файлы через подходящий GitHub-клиент; либо восстановить каркас из геометрического исходника/чертежей.
2. Проверить соответствие исходников архивам и наличие всех зависимостей.
3. Запустить рендер OpenSCAD для 0°, 40°, 80°, проверить полный цикл.
4. Проанализировать методику прошлых булевых тестов; их выводы не переносить на изменённую конструкцию.
5. Сохранить точные скрипты, версии инструментов и результаты проверок.

**Безопасность:** все эти CAD-модели являются исследовательскими демонстраторами и не предназначены для эксплуатации на теле без новых расчётов, прототипирования и профессиональной оценки.
