# v0.5h — разборный шарнир большого пальца: простая металлическая полоса + печатный барабан

Дата 2026-11-10. Исходное ограничение — [мастер-промт v4.2](../../docs/MASTER_PROMPT_v4.2.md). **Это настольная модель отдельного MCP, не готовая и не безопасная для ношения кисть.**

## Вариант изготовления без дорогих станков

- Металлическая полоса **34×12×2 мм**, отверстия Ø3,3 мм с центрами x=0 / 7,5 / 14 / 23 мм, y=0; стандартная разметка, ножовка, тиски, обычное сверло, напильник. Материал, отверстия, допускаемые усилия и нержавеющая защита пока не утверждены.
- Ось-кандидат Ø3 мм, три винта М3 и три стандартные шестигранные гайки; реальные длины/посадки и удержание оси подлежат проверке.
- Печатная проксимальная фаланга, отдельный печатный барабан с геометрической канавкой, неподвижная вилка с направляющей. FDM **только для проверки формы**, не для силовой эксплуатации.

## Выполненные проверки

[build_reinforced_mcp.py](build_reinforced_mcp.py) генерирует 11 CAD-тел. Локально проверены **61 дискретное положение MCP 0–60°**, **671 проверка валидности тела**, **2196 проверок пар**, **362 точных BRep-кандидата**, **0 запрещённых проникновений свыше 0,02 мм³ в выбранных парах**. Преднамеренно исключённые соединения перечисляются в отчёте (оси/отверстия, винты/детали, металлическая полоса/фаланга). Нулевые проникновения не доказывают плотность или прочность таких соединений. Непрерывная траектория и полный корпус кисти НЕ проверены.

**Независимый [qa_interfaces_v05h.py](qa_interfaces_v05h.py) выявил два блокера:**
1. Головки двух М3 выходят за прежний резерв локального пыльника `z≤12` мм на **0,3 мм** уже без толщины стенки; внешний чехол нужно перепроектировать.
2. Ось пересекается по длине с металлической пластиной только на **1,8 мм** из её толщины 2 мм; надёжная осевая фиксация не создана. У самого печатного барабана контакт со штифтом по оси отсутствует; нагрузка должна идти через болты на полосу. Проверка крепёжного силового пути ещё не проводилась.

Отдельный [beam_fem_v05h.py](beam_fem_v05h.py) — **только одномерный** балочный конечный элемент для гипотетической пластины 12×2 мм и консоли 10 мм при E=200 ГПа, НЕ расчёт реальной 3D-детали: идеализированные напряжения 12,5 / 25 / 62,5 МПа при 10 / 20 / 50 Н, численное решение совпало с балочной формулой на сетках 2/4/8/16 элементов. **Отверстия, материал фактической партии, контакт, нагрузка на винты, усталость, коррозия, динамика и 3D-сходимость не учтены**; эти значения не являются разрешением нагрузить протез.

## Как воспроизвести

Из каталога `v0.5h`, с Python и CadQuery:

```bash
python build_reinforced_mcp.py
python qa_interfaces_v05h.py
python beam_fem_v05h.py
```

Получаются STEP (0/20/40/60°), STEP-заготовка полосы, STL **FDM_SHAPE_ONLY**, JSON-аудит и проверка интерфейсов. Отдельный файл с чертежом полосы `drill_pattern_REFERENCE.svg`/PNG есть в локальном ZIP текущего чата; масштаб бумажной печати всегда сверять штангенциркулем. Бинарные CAD-файлы не загружены в GitHub, но генерируются из исходников.

## Статус безопасности и следующая версия

**REWORK / ONLY BENCH SHAPE MOCK.** Нет реально заанкерованного и испытанного троса, пружины, аварийного сброса при заклинивании/отказе питания, обоснованной оси и реального пыльника. Не проверены полный 25-/36-тельный корпус, электрическая/ЭМГ часть, 8 хватов, скорость 1,5 с под нагрузкой, 10 кг на четырёх пальцах, IP54 и пригодность для использования на теле. Не утверждать закупку силовых деталей до расчётов и физической проверки.
