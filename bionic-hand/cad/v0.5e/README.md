# v0.5e — предварительная проверка размещения троса MCP рядом с пыльником

Дата: 2026-11-10. **Новый ограниченный исследовательский подэтап; НЕ продолжение/замена неподтверждённого локального 36-тельного CAD.** Базовый исполняемый генератор в GitHub — v0.5d (25 тел / 13 поз). В разговоре отдельно сообщалось о 36 телах / 14 позах / 8820 парах; скрипты и точный SHA этого результата не представлены в GitHub, поэтому повторная верификация не заявляется.

## Цель

До размещения второго привода большого пальца проверить, не перекроет ли текущий резерв пыльника простую тросовую трассу MCP. Имеющийся `protection_reserve.json` задаёт локальный короб x -16…7, y -7…7, z -10…10 мм, **но не настоящую герметичную защиту**.

## Файлы

- `thumb_flex_study_v05e.py` — воспроизводимый двухмерный расчёт геометрии троса с вращающейся вместе с CMC рамой координат; создаёт `route_study_v05e.json` с 32 точками четырёх вариантов.
- `test_thumb_flex_study_v05e.py` — пять независимых тестов инвариантов (в текущей рабочей среде 5/5 пройдено).
- `thumb_route_2d_v05e.scad` — редактируемая OpenSCAD-схема положения троса, оси и старого резерва пыльника (проверен экспорт 2D SVG).
- `route_study_summary_v05e.json` — сохранённый в GitHub краткий отчёт с числовыми результатами; подробный файл регенерируется скриптом.

## Результат и расхождения

Принят только для расчётного исследования: якорь x=12 мм, направляющая x=-12 мм, совпадающие y=5/6/7/8 мм, плоский прямой участок троса; радиус прокси-проушины 6,25 мм и дополнительный зазор 0,75 мм. В исследованном диапазоне MCP 0…20°:

| y, мм | Выход за радиальный прокси | Выход из старого резерва по y | Условный ход троса 0…20°, мм |
|---:|---|---|---:|
| 5 | Есть | Есть | 2,101 |
| 6 | Есть | Есть | 2,448 |
| 7 | Нет | Есть | 2,796 |
| 8 | Нет | Есть | 3,143 |

**Ни один из четырёх плоских путей не прошёл обе упрощённые проверки.** Это не доказательство, что тросовый привод невозможен. Это предупреждение, что прямой путь нельзя принять без изменения расположения, перехода на другой слой z, защищённого направляющего канала или пересмотра эластичного пыльника.

При y=7 мм и условных r=3 мм барабана, КПД 0,6, плече 58 мм: на кончике 5 Н требует около 0,207 Н·м на барабане и 41,43 Н натяжения троса; это грубая расчётная оценка. Ранее заявленные 1,75 мм хода / 25° барабана относятся к **другой, пока не воспроизведённой передаче**. Не смешивать их с текущими 2,796 мм / 53,39°.

Привод MG90S НЕ утверждён: паспортный stall-момент ≈0,1765 Н·м при 4,8 В не является непрерывным. Нет проверенного привода сгибания MCP, IP-рычага, CAD-совместимости всех тел, концов крепежа, 3D-маршрута троса через CMC, троса с направляющими, пружины возврата, аварийного размыкания, оболочки, IP, FEA или физических измерений.

## Воспроизведение

Из этого каталога:

```bash
python thumb_flex_study_v05e.py
python -m unittest -v test_thumb_flex_study_v05e.py
openscad -D 'flex_deg=20' -D 'route_y=7' -o thumb_route_20deg_v05e.svg thumb_route_2d_v05e.scad
```

Никаких дополнительных Python-зависимостей не требуется. Схема 2D — **не производство деталей**.

## Следующее действие (v0.5e-CAD интеграция)

1. Получить или заново построить воспроизводимую позднюю 36-тельную сборку, сохранив её геометрию и привязку к предыдущим исходникам.
2. Ввести реальный 3D-направляющий/привод в MCP, объединённый с CMC: жёсткие крепления, тяга или трос и возврат, запас по пыльнику с учётом всего sweep, доступ к стопору.
3. Прогнать полный BRep-аудит по всем телам во всех позах и обеспечить непрерывный контроль траектории; не использовать старый результат 8820 пар как доказательство для нового маршрута.
4. Рассчитать двигатель с учётом фактического плеча, тягового усилия, срока службы, тепла и аварийного освобождения. Не заявлять 8 хватов, 10 кг, 1,5 с под нагрузкой, IP и ношение без испытаний.

Согласованные геометрические размеры и мастер-промт v4.2 не изменены. `main` не изменять.

## Анимация модели прокладки троса

Исходник [render_route_animation_v05e.py](render_route_animation_v05e.py) строит **только двумерную аналитическую анимацию** положения троса при MCP 0…20° за условные 1,5 с, а также PNG. Запуск из этого каталога: `python render_route_animation_v05e.py` (зависимости matplotlib, Pillow, ffmpeg для MP4). Он **не** анимирует ранее сообщённые 36 тел, не подтверждает реальную скорость привода и не решает проверку пыли/влаги. GIF/MP4/PNG получены локально и доступны в ZIP текущей беседы, бинарные файлы анимации в GitHub не загружены. [Сверка мастер-промта](../../docs/MASTER_PROMPT_COMPLIANCE_v05e.md).
