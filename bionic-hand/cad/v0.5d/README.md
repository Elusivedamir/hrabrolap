# v0.5d — воспроизводимый шарнир основания большого пальца

Дата: 2026-11-10. Этап **CAD-механики v0.5 с частичными проверками кинематики v0.6**. Физический прототип ещё не собран. Это новая разработка от доступных исходников, не восстановление недоступной 24-тельной версии по описанию.

## Что изменено

- Большой палец соединён с ротором через геометрически построенную вилку и поперечную ось MCP. Отверстие фаланги и отверстия вилки соосны; старое перекрытие ротора с проушиной устранено в проверенных позах.
- Добавлена ось Ø3 мм с головкой и канавкой, а также отдельный CAD-образец C-образного стопора. Стопор пока условный: серийный артикул, допуски, материал и удерживающее усилие не выбраны.
- Вилка и ротор в этом исследовании образуют одно связное CAD-тело с соединительной перемычкой. Это вариант примерочного макета. Дешёвая производственная конструкция из стандартного вала и отдельного крепления ещё требует расчёта; нельзя считать сложную монолитную деталь утверждённой металлической закупкой.
- Поперечное сгибание MCP исследовано отдельно от противопоставления CMC, в диапазоне 0…20°. Угол MCP и угол IP пока задаются программно; отдельного размещённого двигателя сгибания нет.
- Для устранения геометрического конфликта пробный центр MCP расположен в `P=B+14A` вместо `B+6A`: перенос на 8 мм вдоль оси CMC. Это компоновочная гипотеза, не антропометрический размер и не доказанный минимум. Уплотнение и окончательная толщина основания потребуют совместной оптимизации.
- Сохранены длина ладони 122 мм, предварительная ширина 85 мм, длины четырёх пальцев 75/84/78/61 мм, длины большого 33+25 мм и резерв запястья ≤50 мм. Соответствие всей наружной оболочки этим габаритам пока не подтверждено; выступ моста CMC остаётся открытой задачей.

## Что проверено

| Проверка | Результат | Ограничение |
|---|---|---|
| Качество твёрдых тел | 25 тел × 13 поз = 325 валидных состояний; каждое содержит один solid | Только изображённые детали |
| Все модельные пары | 3900 пар; после AABB 434 точные проверки BRep | Проверены 13 положений, не непрерывная траектория |
| Пересечения | 0 объёмных проникновений выше 0,02 мм³ | Исключений для перекрытия деталей нет; нулевое пересечение не доказывает посадку/прочность |
| Геометрия MCP | Ось Ø3, отверстия Ø3,2; пространство вилки 4,4, проушина 3,3 мм | Боковой зазор по 0,55 мм — макетная гипотеза, не окончательный допуск |
| Сгибание MCP | Проверены 5/10/15/20° при противопоставлении, а также 20° в двух других положениях CMC | Восемь функциональных хватов и контакт с предметами не проверены |

Подробные исходные позы, версии ПО и все результаты: [audit_v05d.json](audit_v05d.json), воспроизведение: [audit_v05d.py](audit_v05d.py). Название позы `pinch` означает сохранённый сценарий, а не доказанный точный захват. После смещения MCP параметры точного хвата нужно подобрать заново с учётом контактных поверхностей.

## Пыль и влага

[protection_reserve.json](protection_reserve.json) задаёт резерв вокруг MCP в его локальных координатах: x −16…7, y −7…7, z −10…10 мм. Это место для будущего пыльника и доступа к обоим концам оси; не готовый пыльник и не доказанный свободный объём всей сборки. Его совместимость с тягой и оболочкой ещё не проверена. Пыльник должен сниматься для ремонта и не мешать аварийному освобождению.

Вал CMC, разъёмные крышки, кабельные вводы, ЭМГ-соединения и зарядка требуют собственных барьеров. Влагозащита, нагрев с чехлами и IP не проверены. Общий план — [PROTECTION_v05c.md](../../docs/PROTECTION_v05c.md).

## Сборочная последовательность макета

1. Зафиксировать ротор/вилку в настольном держателе, доступном для работы одной рукой.
2. Расположить проушину проксимальной фаланги между щеками вилки.
3. Совместить три отверстия и вставить модельную ось со стороны головки.
4. Установить соответствующий выбранному стандарту стопор и проверить осевую фиксацию и свободный ход. **Серийный стопор пока не выбран; CAD-образец не является готовой инструкцией его изготовления.**
5. Проверить открытие/закрытие вручную без мотора и нагрузки; после выбора реальных компонентов измерить зазоры и повторить проверки.

Эта последовательность описывает замысел доступной сборки. До выбора реальных посадок, материалов, крепежа и проверки удержания оси модель не является изготовительным комплектом. FDM-детали допустимы для примерки формы; силовую эксплуатацию они здесь не подтверждают.

## Воспроизведение

Из `bionic-hand/`, зависимости из `../archive_review_v05c_r1/requirements.txt` (относительно этого README). Предварительно должен быть создан восстановленный каркас.

```bash
python cad/v0.5/rebuild_baseline_v04.py
python cad/v0.5d/build_v05d.py
python cad/v0.5d/audit_v05d.py
python cad/v0.5d/render_v05d.py
```

Зависимости `v0.5/`, `v0.5b/` и `archive_review_v05c_r1/` должны сохраняться рядом. Генератор создаёт STEP-сборку, отдельные STEP и пять GLB-сцен; рендер — два PNG. В GitHub сохранены исходники, JSON-отчёты, сжатая STEP-сборка и одно PNG-превью. Отдельные STEP, GLB и второе превью остаются воспроизводимыми локальными результатами. MP4 на этом этапе не создавался.
