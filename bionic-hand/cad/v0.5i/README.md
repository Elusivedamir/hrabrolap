# v0.5i — проверка доступных возвратных пружин (отрицательный результат)

Дата: 2026-11-10. Продолжение от **v0.5h**. Цель — найти недорогой возврат MCP из готовой пружины, без заказного станка.

[Скрипт spring_screen_v05i.py](spring_screen_v05i.py) рассматривает 64 условные трассы между неподвижной и вращающейся точками (2 варианта x × 2 y × 2 x на фаланге × 8 локальных уровней z). У всех кандидатов удлинение пружины монотонно в 61 аналитической точке 0–60°. Для **7 дискретных поз** на кандидат проверено модельное прямолинейное тело Ø2 мм с исключёнными по 3 мм концевыми участками против 11 CAD-тел отдельного шарнира v0.5h.

### Результат

- **16 кандидатов** не дали обнаруженных пересечений в 7 позах, но **вышли за прежний локальный резерв пыльника по z**.
- **48 кандидатов**, помещавшихся в резерв по z, дали пересечения с модельными деталями.
- **0 вариантов** одновременно обеспечили оба упрощённых условия.

Это не доказательство невозможности пружины, а **причина НЕ утверждать** ни одну рассмотренную компоновку. Настоящие пружины, проушины, крючки, монтажные поверхности, измеренная жёсткость и взаимодействие с самотормозящим редуктором не моделировались.

### Решение

Сначала исследовать **готовую малую торсионную пружину вокруг оси MCP** с новым удерживаемым стандартным пальцем и простыми опорами для концов, без CNC. Но подбор диаметра проволоки, витков, момента, полки для ноги пружины и габаритов с пыльником требует нового CAD и физической проверки. Внешнюю натяжную пружину в прежнем объёме не утверждать.

**Аварийное освобождение не выполнено.** Отключение питания НЕ гарантирует раскрытие, если привод самотормозящий. До проверки работающего механического освобождения не подключать к телу и не использовать с нагрузкой.

### Повторение

С установленным CadQuery, находясь в v0.5i рядом с v0.5h:

```bash
python spring_screen_v05i.py
```

Создаёт полный `spring_screen_v05i.json`. Сохранять отрицательные результаты и явно отмечать, какие оболочки проверялись.
