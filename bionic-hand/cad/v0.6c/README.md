# v0.6c — пыльник: проверка фактического габарита крепежа и пружины

Дата 2026-11-11. Это **геометрический контроль габарита**, а не прототип герметичного чехла и не присвоение класса IP.

Изолированный MCP v0.5h имеет неподвижный резерв пыльника `x[-16,7], y[-7,7], z[-10,12]` мм. Вращающиеся головки первых двух винтов М3 моделируются цилиндрами Ø5,4 мм. При сгибании MCP на 60°:

- Головка винта №1 (центр x=7,5 мм в системе фаланги) полностью находится внутри x-среза старого пыльника, но её верх по y достигает **~9,195 мм**, то есть выходит за +7 мм на ~2,195 мм.
- Головка винта №2 (центр x=14 мм) частично находится в старом x-срезе и достигает **~14,824 мм по y**, то есть выходит на **~7,824 мм**. Здесь требуется выход гибкого чехла на движущуюся часть, а не простое расширение неподвижного коробка.
- Обе головки находятся на z=11,4…12,3 мм, и уже превышают исходное z≤12 на 0,3 мм.
- Удлинённая модельная ось торсионной пружины из v0.5j имеет головку до z=-12,6 мм, на **2,6 мм ниже** прежней границы.

Минимальный **сухой жёсткий объём по z** без зазоров и стенок составил бы диапазон `[-12,6;12,3]` = **24,9 мм**, тогда как текущий диапазон 22 мм. Это НЕ утверждённый размер будущей оболочки и не расчёт совместимости с ладонью 122×~85 мм. Для стенок, зазоров, деформации и обслуживания потребуется дополнительный запас, который пока нельзя обосновать без реального образца.

## Конструктивное решение без дорогого оборудования

1. Не ставить жёсткую прямоугольную крышку поверх движущегося шарнира. Делать **съёмный эластичный пыльник/манжету** (TPU или покупной подходящий эластомер), привязанную к неподвижной вилке и движущейся фаланге без сдавливания троса.
2. Отдельно защитить **электронный отсек** сменной прокладкой, стандартными кабельными вводами и крышкой; электрические соединения ЭМГ не покрывать неподходящей герметизирующей заливкой.
3. Не прятать аварийный механизм раскрытия под несъёмный чехол. Съёмность/очистку одной рукой и невозможность защемления проверить на стенде.
4. Для защиты от пота, песка и дождя нужны физические испытания на отдельном образце **без контакта с телом**. IP54 не заявляется.

Новые результаты дополняют [проверку троса v0.6b](../v0.6b/README.md). Полная CAD-оболочка и измерение деформаций пыльника ещё не выполнены.
