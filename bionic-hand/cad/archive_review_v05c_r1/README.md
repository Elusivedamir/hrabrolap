# Проверка раннего архива v0.5c — привод противопоставления, аудит и защита

Исследовательский CAD, 2026-11-10. **Не готовый к изготовлению или ношению протез.** Проверка доступного раннего 23-тельного архива по MASTER_PROMPT v4.2; это НЕ замена поздней 24-тельной v0.5c; критические антропометрические размеры не менялись.

## Что восстановлено и исправлено

- Отдельный кандидат привода CMC: номинальная оболочка MG90S, одинаковые кривошипы R14,5 мм, тяга 49,8197 мм, поворот 89,056° вокруг оси [-0,01760; 0,88512; 0,46504]. Это передача 1:1, без выигрыша момента.
- Отдельный привод сгибания большого пальца остаётся обязательным, но ещё не размещён. IP в CAD задан углом 0…25°, а не рассчитанным работающим приводом.
- Восстановлены Python-исходники из прежнего архива и исправлены относительные пути к v0.5/v0.5b. Оригинальный генератор и отчёты сохранены в `history/`, происхождение — в `provenance.json`.
- Найдены и исправлены отсутствующие отверстия двух кривошипов под оси Ø3 мм: отверстия Ø3,2 мм, временные модельные оси длиной 8 мм. Осевое удержание, шайбы и реальные допуски ещё не разработаны.
- Для новой геометрии жёсткие повороты выполняются через rotate/translate, сохраняя аналитические поверхности. Прежний transformGeometry давал невалидный BRep thumb_prox в 6 повернутых позах на CadQuery 2.7.0.
- Исправлена анимация: проксимальная фаланга вращается вокруг B+6A, а не B. Переходы заданы по 1,5 с; это не измеренная скорость механизма.
- [Аналоги](../../docs/ANALOGUES_v05c.md) и [защита от пыли/влаги](../../docs/PROTECTION_v05c.md) зафиксированы отдельными документами. `protection_parameters.json` содержит гипотезы резервов, а не параметры утверждённых уплотнений.

## Что блокирует сборку

Нет завершённых креплений rotor/prox, spline/horn, осевой фиксации, полного силового пути MCP/каркас/запястье, аварийного освобождения, второго привода большого пальца, проводов, платы и батареи. Ступица качалки отделена от модельного шлица по оси; простой нулевой collision не обнаруживает отсутствие соединения.

Модельный вал CMC R4 мм и отверстие R4,3 мм дают радиальный зазор 0,30 мм, который не является уплотнением. Между верхним кольцом и плечом только 0,30 мм по оси. Мост выступает до z≈52,7 мм за предварительную половину ширины ладони 42,5 мм; совместимость с наружной оболочкой/основанием большого пальца не решена. Батарея, тепло, ЭМГ, 8 хватов, FEA, 10 кг, IP и эксплуатация на теле не проверены.

MG90S — кандидат макета. Паспортный stall при 4,8 В 1,8 кгс·см ≈0,1765 Н·м не является длительным рабочим моментом. При условном плече 58 мм это лишь ~3,04 Н теоретического предела до потерь, а не доказанная сила кончика. Мотор не утверждён для силового удержания или влагозащищённой кисти.

## Воспроизведение

Из каталога `bionic-hand/`, в отдельном Python-окружении, установить `cad/archive_review_v05c_r1/requirements.txt`. Не смешивать его с историческим набором v0.5 (CadQuery 2.8.0): текущие результаты получены на Python 3.12.14, CadQuery 2.7.0 и OCC, поставляемом с ним.

```bash
python cad/v0.5/rebuild_baseline_v04.py
python cad/archive_review_v05c_r1/build_thumb_motor_v05c.py
python cad/archive_review_v05c_r1/audit_all_pairs_v05c.py
python cad/archive_review_v05c_r1/review_protection_v05c.py
python cad/archive_review_v05c_r1/render_preview_v05c.py
```

Генератор создаёт отдельные STEP, сборку STEP, GLB и `geometry_and_drive_v05c.json`. Образец уплотнения — `protection_sample/gasket_joint_concept.step`, он в своей системе координат, вне сборки кисти. Agg-превью использует matplotlib и не требует X-сервера; оно не заменяет CAD-проверку. Старый `audit_motor_v05c.py` теперь перенаправляет на строгий аудит всех модельных пар и возвращает ненулевой код при ошибках.

Для MP4 нужен `ffmpeg`, шрифт DejaVuSans и рабочий OpenGL/X-контекст VTK. Затем `python cad/archive_review_v05c_r1/animate_motor_v05c.py`; сначала проверяются матрицы, потом запускается рендер. Отсутствующий видеорезультат не считать созданным.
