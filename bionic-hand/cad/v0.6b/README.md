# v0.6b — независимая 3D-проверка троса: найдено пересечение в v0.5h

**Дата:** 2026-11-11. Изолированный инженерный макет MCP, не изделие для ношения. Строго по [мастер-промту v4.2](../../docs/MASTER_PROMPT_v4.2.md). **Проверка не использует исходный критерий «0 пересечений» как доказательство механической работы.**

## Обнаруженная ошибка

В [v0.5h](../v0.5h/README.md) 11 CAD-тел проверялись без настоящего троса. После введения упрощённого 3D-троса Ø1,2 мм (цилиндрические участки с шагом дуги не более 3°) **исходный печатный барабан с соединительной частью шириной 10,4 мм пересекает линию троса**. При 30° обнаружено 0,13842 мм³ проникновения, при 45° — 1,92139 мм³, при 60° — 4,06531 мм³ в сумме по отрезкам. Это *модельные объёмы*, не эксперимент с реальным тросом; сумма сегментов не является точным объёмом непрерывной оболочки.

Важно: старый результат нуля пересечений **не отменён для своих 11 тел**, но он не относится к тросу, которого не было в исходной CAD-модели. Поэтому утверждать, что собранный привод свободно работает в этих положениях, было бы ошибкой.

## Простой геометрический вариант

Сузили соединительную часть барабана до ширины **5,6 мм** (полуширина 2,8 вместо 5,2), сохраняя обычную печать и 3-мм стандартную ось. Для неё в локальном CadQuery проверили **61 положение от 0 до 60° с шагом 1°**, все 61 тела были валидны; максимальная сумма пересечений с моделируемым тросом **0,000064 мм³** в 60°. Это меньше принятого порога 0,02 мм³, но **не доказывает реальный свободный ход или износ**.

| Угол | Исходная часть 10,4 мм, мм³ | Вариант 5,6 мм, мм³ |
|---:|---:|---:|
| 0° | 0 | 0 |
| 30° | 0,13842 | 0 |
| 45° | 1,92139 | 0 |
| 60° | 4,06531 | 0,000064 |

Исходная геометрия проверена в 13 угловых положениях с шагом 5°, вариант — в 61 положении. На 5 независимых тестовых условиях проверки геометрии/математики — 5/5 OK.

**Критический недопуск:** после сужения вокруг Ø3,3 мм винтового отверстия остаётся лишь **1,15 мм номинального печатного материала с каждой стороны**, без допуска печати. Проверок на срез, расслоение, удар, износ и усталость нет. **НЕ использовать узкий барабан для работы под нагрузкой и НЕ надевать на тело.** Нужен другой силовой путь с доступной металлической плоской полосой *ниже* зоны движения троса и отдельным подшипниковым узлом; нельзя просто утолщать в сторону троса.

## Пыль и влага

Геометрическая проверка выполнена **без настоящего пыльника, прокладки кабельного ввода, крышки моторного отсека и всей кисти**. Трос при изменении угла может работать по канавке, но протирание и загрязнение пока не оценены. IP54 и более высокие степени **не подтверждены**.

## Повторение

Сохранены [исходник](cable_sweep_v06b.py), [регрессионные тесты](test_cable_sweep_v06b.py), [сводка результатов](audit_summary_v06b.json). Требуется Python с CadQuery, рядом папка `cad/v0.5h`:

```bash
python cable_sweep_v06b.py
python -m unittest -v test_cable_sweep_v06b.py
```

При запуске создаются подробный JSON-отчёт с числами по углам и STEP/STL **только для ненагруженной примерки формы**. Превью и экспортированные двоичные файлы приложены в архив текущей беседы; текстовые файлы сохраняются в GitHub.

## Следующий инженерный контроль

Далее нужна не очередная «идеальная» анимация, а **реальный силовой способ закрепить трос на барабане**, возврат, защита при отказе питания, физически собираемый стандартный осевой крепёж и доступный пыльник с учётом выступающих головок. Каждый из этих узлов должен пройти собственную проверку до заявлений о функциональном протезе.
