# Предварительный интерфейс ЭМГ для CAD v0.5

**Функция:** автономное управление кистью двумя каналами поверхностной ЭМГ, расширение лишь при необходимости. Физические электроды, места на культе и тип сигнала ещё не проверялись.

- Электроды не размещать на схеме без измерения реально доступных мышечных сигналов специалистом.
- В объёме кисти предусмотреть место для контроллера, драйверов, защищённого питания и проводки; в 50-мм интерфейсном модуле — только необходимое соединение.
- В дальнейшем выбрать один безопасный серийный ЭМГ-тракт с подходящими схемами защиты, чтобы не проектировать небезопасное самодельное измерение на теле.
- Два канала — стартовая гипотеза, не доказательство распознавания всех восьми команд. Приложение Android должно только настраивать, не участвовать в обязательном контуре управления.
- Не подключать контактные электроды к самодельной схеме с небезопасным USB/сетевым питанием. На теле только после оценки электробезопасности.
- По датчикам положения/тока сначала использовать встроенные функции привода и драйвера. Не добавлять дублей без инженерной причины.

**На этапе v0.5 ЭМГ не измерялась и система управления не запускалась.**
