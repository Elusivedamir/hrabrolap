# v0.5j — компоновка покупной торсионной пружины (только место под витки)

[Исходник](torsion_layout_v05j.py) строит локальную 3D-модель **оболочки предполагаемых витков**, а не реальную винтовую пружину: внешний диаметр 6,6 мм, внутренний 3,7 мм, осевая длина 2,3 мм, z от -10,8 до -8,5 мм. Для освобождения места под витки гипотетическая ось Ø3 мм удлинена до z=-11,5…8,8 мм; головка вниз до -12,6 мм. Критические размеры пальцев не изменены.

**61 поза / 732 проверки тел / 610 проверок столкновений оболочки витков с другими телами / 0 выявленных столкновений**, исключая заведомый контакт витков со штифтом. Это исключительно **CAD-размещение витков**. Лапки, проушины крепления, жёсткость, кручение проволоки, стопор на оси, удержание, реальный пыльник и открытие при заклинивании/выключении питания отсутствуют. **Сам пыльник тоже надо расширить вниз: головка выходит за прежний резерв z=-10 на 2,6 мм**, не считая толщины чехла.

Саму пружину не покупать по этому файлу. После получения паспорта серийной пружины, примерки и оценки момента доработать вилку, крепление и осевой фиксатор. На теле не использовать.

```bash
python torsion_layout_v05j.py
```

Создаёт JSON и три STEP-положения. Бинарные STEP в локальном архиве, текстовый генератор — в GitHub.
