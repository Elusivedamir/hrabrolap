# v0.5g — простой барабан MCP, воспроизводимый 3D-CAD

2026-11-10. По [мастер-промту v4.2](../../docs/MASTER_PROMPT_v4.2.md) и [правилам обычной мастерской](../../docs/LOW_COST_MANUFACTURING_RULES.md). **Изолированное исследование шарнира большого пальца, НЕ полный протез и НЕ силовая деталь.**

## Что создано

- [build_capstan_v05g.py](build_capstan_v05g.py): редактируемый CadQuery-генератор 4 CAD-тел: вилка с направляющей, фаланга с барабаном, условная ось Ø3 мм, условный стопор.
- [test_capstan_v05g.py](test_capstan_v05g.py): 7/7 автоматических тестов пройдены локально.
- [render_capstan_v05g.py](render_capstan_v05g.py): превью и *идеальная* анимация, не реальная скорость/физический трос.
- [strength_screen_v05g.py](strength_screen_v05g.py): заведомо грубая балочная проверка печатного рычага; **не FEA**.
- [audit_summary_v05g.json](audit_summary_v05g.json): проверенные числа и ограничения. Полный результат генерируется скриптом локально в `audit_capstan_v05g.json`.

**Локальный CAD-аудит:** 61 поза от 0 до 60° с шагом 1°. 244 проверки валидности четырёх тел; 244 проверки четырёх заранее выбранных пар; 244 точных BRep-кандидата; ноль объёмных проникновений выше 0,02 мм³ *в этих парах*. Преднамеренные соединения ось/отверстие исключены, их реальные посадки ещё не рассчитаны. Не проверен непрерывный ход, все пары полной 25-/36-тельной сборки или работоспособность под нагрузкой.

## Идеальная кинематика

Барабан Ø10,4 мм; трос условно Ø1,2 мм, радиус **центра троса** 5,8 мм, z=9,6 мм. Вращающийся барабан + конец каната **физически не соединены на этом CAD**; канавка и удержание узла отсутствуют. Длина троса при 60° ≈ **6,074 мм**, угловой ход барабана двигателя r=3 мм ≈ **116°**, средняя скорость при условных 1,5 с ≈ **12,89 об/мин** (без нагрузки, без IP и без движения второй фаланги).

Условные силы на кончике *только большого пальца* при плече 58 мм, КПД 0,6, радиусе моторного барабана 3 мм:

| Усилие на кончике (гипотеза) | Условное натяжение троса | Условный момент мотора |
|---:|---:|---:|
| 1 Н | 10 Н | 0,050 Н·м |
| 2 Н | 20 Н | 0,100 Н·м |
| 5 Н | 50 Н | 0,250 Н·м |

Это **не утверждённые характеристики**, не удержание пакета 10 кг (оно относится к четырём другим пальцам).

## Важный выявленный риск

Тонкая прямоугольная перемычка из печатного пластика между фалангой и барабаном предварительно имеет ширину 3,2 мм и толщину 2,0 мм. Консервативный балочный эквивалент при условном плече 10 мм даёт ~93,8 МПа при сценарии 2 Н на кончике и ~234,4 МПа при 5 Н. Это **не подтверждённые напряжения детали и не FEA**, а признак того, что нынешний печатный вариант **не допускается к силовому применению**. Перед изготовлением сравнить простую металлическую пластину, которую можно отрезать/просверлить в обычной мастерской, и усиленную FDM-форму; подтвердить FEA и стендом.

Другой риск — радиус изгиба стального велосипедного троса Ø1,2 мм всего ~4,8 его диаметра. Износ/усталость неизвестны; рассмотреть доступный плетёный UHMWPE-шнур, подтвердив крепление, износ и допустимый изгиб. **Никакая покупка ещё не утверждена.**

## Пыль и влага

Предложенная локальная зона `x -16…7, y -7…7, z -10…12` мм резервирует только идеальную центральную линию троса с радиусом; **всю движущуюся фалангу/перемычку она не охватывает**. Примерочная направляющая заканчивается на z=11,4 мм, оставляя лишь 0,6 мм до гипотетической границы, а не доказанную толщину уплотнения. Потребуется сменный гибкий пыльник с широким выходом, а отдельно защищённый электронный отсек. **Никакого подтверждённого IP, влагостойкости или безопасной зарядки нет.**

## Дешёвое изготовление без CNC

| Деталь | Первая альтернатива | Ограничения |
|---|---|---|
| Корпус направляющей / проверочный барабан | PETG-FDM из локальных `FDM_SHAPE_ONLY*.stl` | Только проверка формы и ручного хода |
| Ось MCP Ø3 мм | Готовый гладкий штифт или плечевой винт со стандартной фиксацией | Артикул/посадки/удержание не утверждены |
| Несущая перемычка | **Простая пластина** из рыночного металлопроката, разметка/сверление; или усиленный печатный вариант после проверки | Без расчёта и теста не нагружать |
| Трос / шнур | Стандартные расходные материалы из рыболовного или велосипедного магазина | Выбрать по радиусу изгиба, качеству крепления, долговечности |
| Пыльник | Сменная TPU/резиновая манжета/чехол | Не доказано обеспечение IP, не мешать аварийному сбросу |

Рассмотрен [сервопривод E9821-20 за опубликованные ~1850 ₽](https://www.rc-russia.ru/products/e9821-20-Servoprivod-tsifrovoy-metallicheskiy-20-kg): паспортные 20 кг·см — не длительный момент; габарит и температура не проверены внутри ладони. Для сравнения микросерво FS90MG имеет по одной документации номинально ~0,7 кг·см (~0,069 Н·м) при 6 В — ниже условно необходимых 0,1 Н·м для 2 Н на кончике. **Ни один мотор не выбран и не заказан.**

## Повторение

Из данного каталога после установки CadQuery / numpy / matplotlib / Pillow (ffmpeg — для MP4):

```bash
python build_capstan_v05g.py
python -m unittest -v test_capstan_v05g.py
python strength_screen_v05g.py
python render_capstan_v05g.py
```

Экспортируются STEP 0/20/40/60°, два `FDM_SHAPE_ONLY` STL, полный JSON-аудит, PNG/GIF/MP4. Двоичные результаты хранятся в архиве текущей беседы, **в GitHub сохранены редактируемые текстовые исходники**.
