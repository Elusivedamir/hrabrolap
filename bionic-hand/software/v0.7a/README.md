# v0.7a — безопасный программный каркас двухканальной ЭМГ (только симулятор)

Дата: 2026-11-11. Это отдельный **программный тестовый проект**, не исполняемая прошивка мотора и не ЭМГ-прибор для контакта с кожей. Двухканальное миоэлектрическое управление остаётся обязательным по [мастер-промту v4.2](../../docs/MASTER_PROMPT_v4.2.md).

## Файлы

- [emg_safety_state_v07a.py](emg_safety_state_v07a.py) — автономная детерминированная логика намерения «открыть/закрыть» от двух **синтетических нормированных** каналов.
- [test_emg_safety_v07a.py](test_emg_safety_v07a.py) — 14 сценариев регрессии; в локальном исполнении пройдены **14/14**, без подключения к платам или телу.

Параметры *временно для теста*: 20 мс цикл; 500 мс нейтрального сигнала и отдельный переключатель для разрешения состояния READY; 60 мс подтверждения отдельного жеста; таймаут получения данных 100 мс; искусственные пороги 0,65/0,25. **Это не реальные пороги мышц, не параметры будущей платы и не медицинские рекомендации.**

Алгоритм отбрасывает одновременные сильные сигналы, блокируется при устаревших/некорректных данных, плохом питании, перегреве, перегрузке и ручном запросе освобождения. После FAULT требуется снятие разрешения и отдельная команда сброса.

**Принципиально:** все выходы содержат `hardware_power_permission=False`, даже когда абстрактная команда CLOSE/OPEN обнаружена. Данный код нельзя напрямую подключать к приводам. Срабатывание программного флага ручного освобождения *не является настоящим механическим освобождением*: при самотормозящемся редукторе мотор без питания может оставаться заклиненным. **Независимое механическое освобождение, аппаратный watchdog, безопасное питание/BMS и ЭМГ-изоляция ещё не спроектированы.**

## Повторение

```bash
cd bionic-hand/software/v0.7a
python -m unittest -v test_emg_safety_v07a.py
```

Тесты не нуждаются в Python-библиотеках кроме стандартной. 14/14 подтверждают поведение этой модели в указанных сценариях, но **не безопасность электрического устройства, калибровку на реальных мышечных сигналах, работу восьми хватов или 1,5 с закрытия**.

## Следующее

После выбора реально безопасного двухканального ЭМГ-модуля и микроконтроллера — отдельно проверить схему питания, изоляцию измерителя, аппаратное отключение драйвера, реальный watchdog, реальные отказы проводов и безопасное поведение при механическом заклинивании. Не использовать самодельные неразвязанные электроды на теле, не испытывать на коже до независимой электробезопасной оценки.
