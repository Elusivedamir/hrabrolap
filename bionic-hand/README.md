# Бионическая кисть с нуля / DIY Myoelectric Prosthetic Hand

Проект самостоятельной разработки недорогой **левой миоэлектрической кисти** для сборки без собственной мастерской. **ЭМГ — основной способ управления**; приложение Android — для настроек. Основное требование: не добавлять датчики и сложные узлы без доказанной пользы и соблюдать безопасность.

## Базовые требования
Ладонь 122 × предварительно 85 мм; пальцы: указательный 75, средний 84, безымянный 78, мизинец 61 мм; большой — проектируется. Между культёй и основанием кисти ≤50 мм, включая соединение с гильзой. Восемь хватов, 1,5 с закрытие, 1,5 с открытие. Целевой крючковый хват: пакет 10 кг на четырёх пальцах без большого. **10 кг не является подтверждённой грузоподъёмностью.**

## Важно
Это **исследовательский проект протеза**, не готовое медицинское изделие. Кинематические изображения и CAD-анимации не подтверждают прочность и безопасность. Не использовать на теле до физических испытаний и профессиональной проверки.

## Репозиторий
Проект временно размещён в отдельной ветке `project/bionic-hand` существующего публичного `Elusivedamir/hrabrolap`. Ветка `main` игровой разработки не изменяется. В дальнейшем предпочтителен собственный репозиторий.

Не загружать секреты, персональные медицинские данные и необработанные ЭМГ-записи без отдельного разрешения.
