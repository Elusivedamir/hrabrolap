# Termux: обновление и запуск Храбролапа одной командой

## Первичная установка (один раз)
В Termux, в существующей папке игры:

```bash
cd ~/hrabrolap-new && git pull --ff-only origin main && bash tools/termux-hrabrolap.sh
```

Первая команда забирает новый скрипт из GitHub. Скрипт автоматически добавит маленький исполняемый запускатель в стандартную папку команд Termux.

## Далее — одна команда

| Команда | Что откроется |
|---|---|
| `hrabrolap` | Просмотрщик P3 с 20 залами и 4 боссами |
| `hrabrolap p3` | То же: `p3-review.html` |
| `hrabrolap game` | Игра: `index.html` |
| `hrabrolap art` | Настоящая игра с новыми P3-кандидатами через `index.html?p3Art=1`; сохранения и порт прежние |
| `hrabrolap atelier` | SVG-ателье: `equipment-preview.html` |
| `hrabrolap save` | Просмотр и резервное копирование сохранений: `save-manager.html` |
| `hrabrolap ice` | Отдельное тестовое меню ледяной саламандры: 6 кадров атаки, 6 кадров урона, воспроизведение, скорость, масштаб, проверка альфа-канала и печати |

Каждый запуск обновляет `main` командой `git pull --ff-only origin main`, проверяет сервер на `127.0.0.1:8090`, запускает его при необходимости и открывает выбранную страницу через системный Android-браузер.

## Защита прогресса

- Постоянные адрес и порт **http://127.0.0.1:8090**: `localStorage` остаётся на том же origin; скрипт не удаляет прогресс и не вызывает сброс.
- Если на 8090 уже работает **актуальная** копия проекта, используем её; повторный HTTP-сервер не создаём.
- Если 8090 обслуживает **другой сайт или старые файлы**, процесс не убиваем и порт не меняем автоматически. Скрипт останавливается с понятным сообщением; пришлите скриншот Termux.
- Если `git pull --ff-only` не проходит (локальные изменения, конфликт, сеть, учётные данные), ничего не сбрасываем — сначала разбираем ошибку.
- Смена `HRABROLAP_PORT` допустима только осознанно: новый порт = отдельный браузерный прогресс. При необходимости используйте страницу резервного копирования на прежнем origin.
- Не копируйте URL в командную строку Termux: браузер скрипт откроет самостоятельно, а ссылки вручную открываются в Chrome.
- Для работы автоматического открытия используется встроенный `termux-open-url`; если он не доступен, скрипт пытается открыть Android Intent. Последний резервный вариант — напечатанный URL.

## Проверка

`python3 tests/test_termux_launcher.py` проверяет синтаксис Bash, повторное использование верного сервера, занятый чужим сайтом порт и первый безопасный запуск. В обычной сборке это часть `npm test`.

В текущей беседе нет прямого соединения с Termux пользователя: автоматизация работает **локально на телефоне** после его первоначального запуска.
