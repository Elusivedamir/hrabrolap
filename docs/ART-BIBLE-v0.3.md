# Храбролап — художественный паспорт персонажа и анимации, v0.3

Статус: **SVG-production ПРОБА, не окончательно утверждённая пользователем внешность**. Дата: 15.10.2026.

## Неизменяемый канон (из утверждённых ранее референсов)

- Маленький рыжий полосатый котёнок-рыцарь с огромными **двумя различимыми круглыми глазами** (включая ракурс 3/4), бело-кремовой мордочкой и пушистым хвостом.
- Серебристый шлем открывает глаза; на его правом краю закреплён **розовый цветок**.
- Короткий меч, металлический нагрудник и поножи, пояс с золотой пряжкой, красный шарф/плащ. Большая голова, маленькое туловище, добрый характер и смелая стойка.
- **Строго ламповая 2D**: без псевдо-3D-рендера, фотографических текстур, случайных неоновых эффектов и других несовместимых визуальных языков.
- Рыцарь-рыбак — **отдельный большой персонаж**, не котёнок. Котёнок рыбачить не должен. Седой кот — отдельно торговец.
- Дом обычно виден снаружи; во время отдыха котёнка внутри — появляется видимый интерьер-разрез и тот же котёнок с закрытыми глазами.

## Что сделано фактически

Все кадры в `art/` порождены из **одного исходника** `tools/build_cat.py` с ручными SVG-путями. Никаких встроенных растровых `<image>` в этих SVG нет. Именно это обеспечивает неизменность узнаваемых черт лица в разных позах.

| Ассет | Назначение |
| --- | --- |
| `art/kitten.svg` | Главная стойка |
| `art/kitten-a01.svg` | Подготовка |
| `art/kitten-a02.svg` | Замах |
| `art/kitten-a03.svg` | Резкое движение клинка |
| `art/kitten-a04.svg` | Контакт/проводка |
| `art/kitten-a05.svg` | Возврат |
| `art/kitten-a06.svg` | Возврат в стойку |
| `art/kitten-hurt.svg` | Реакция на удар |
| `art/kitten-victory.svg` | Победная стойка |
| `art/kitten-rest.svg` | Сон (та же голова, шлем и цветок; меч скрыт) |

Длительность атаки в бою: **6 × 78 мс = 468 мс**. В анимационном стенде можно смотреть медленнее (92 мс), чтобы видеть каждый кадр. Стенд открывается отдельно: `animation-studio.html`.

В динамике у удара подвижны рука с мечом, плащ, хвост, корпус и наклон головы. Анатомия/траектории — предмет ручной правки после просмотра пользователем: это SVG-анимационный прототип, не окончательный атлас для всех ситуаций.

## Приёмочные проверки перед следующим шагом

1. Обе радужки видны, нет замыленного глаза/перекрытия шлемом.
2. Основной ракурс и детали совпадают с `references/canon-kitten-approved.png` **по узнаваемым признакам**; художественная плотность ручного SVG пока заметно проще референса — её нужно согласовать.
3. При ударе меч не пересекает глаза, попадает в сторону врага; основной персонаж не просто целиком вращается.
4. Всё читается в размере игрового героя на телефоне, а не только в увеличенном концепт-листе.
5. Нет неверного утверждения о готовности: мастер SVG сейчас только кандидат на художественное утверждение.
6. При покупке брони текущее HP **не увеличивается**; между комнатами текущее HP переносится без лечения; лечит только отдых дома после поражения.
7. Рыбалка и торговец останавливаются при закрытой вкладке; офлайн-награда только за котёнка с ограничением.
8. Никаких изменений экономики/рыбалки/квестов при замене графических ассетов.

## Главные риски

- SVG отличается по живописности от ранее созданной иллюстрации. Не называть финальным без подтверждения.
- Замена кадров `<img>` подходит для первой сборки. Для оптимизации следует в будущем предварительно декодировать спрайты и перейти на атлас/rig, если появится дёрганье на мобильном телефоне.
- Рисунок рыцаря, торговца, подземелья и дома из v0.2 всё ещё необходимо привести к **единому** утверждённому художественному качеству; в v0.3 преимущественно обновлён котёнок.
- Механический swing нужно проверять на попадание визуального кадра в совпадающий с ним момент уменьшения HP врага: пока игровые события происходят сразу, а кадр контакта чуть позже.
