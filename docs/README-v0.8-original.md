# Храбролап: Тихая пристань — v0.8 (ПРОВЕРОЧНАЯ HTML5-СБОРКА)

Основа — оригинальный архив `hrabrolap-v0.7.zip`. Это продолжение существующей игры, а не новый проект. Оригинальные 6 кадров и исторический README не изменены и сохранены в `assets/pose_01.png` … `assets/pose_06.png` и `assets/battle/attack_01.png` … `attack_06.png`.

## Что реализовано в коде

- 100 последовательных волн; каждая десятая — босс (тот же тип монстра, масштаб + корона).
- 8 моделей врагов: слизень, мышь, гриб, летучая мышь, паук, личинка, жук, призрак. Каждому назначены свой тип атаки и CSS-анимация; получение урона анимировано отдельно, смерть — пока преимущественно общая.
- Три **программные** атаки Храбролапа по шесть поз ключевой анимации: рубящий удар, сверху вниз, колющий рывок. Они циклически чередуются в автобою и используют **один сменяемый SVG-меч**.
- **Новый сборный игровой котёнок без нагрудной брони и без встроенного меча** в `art/hero/bare-kitten.svg`. Для узнаваемости использована оригинальная голова из v0.7; туловище без брони переработано и требует художественного согласования. Исторические PNG не подменены.
- Векторные SVG-мечи в `art/weapons/` (железный, рыбья кость, лунный), SVG-нагрудники в `art/armor/`. Они подгружаются как отдельные `<image>`-слои в SVG-риге, анимация оружия происходит изменением transform.
- Магазин и инвентарь: купленные вещи доступны для экипировки; выбранный меч меняет урон и внешний вид сразу в трёх атаках. Существующие апгрейды урона/HP остаются независимыми от покупки экипировки.
- Ведро SVG, улучшение с 12 до 24 мест за 320 монет.
- Убрана цифра «монеты в минуту» из верхней панели. Добавлены кнопки магазина и инвентаря.
- Домик с существующим разрезом во время отдыха, мини-пещера, магазинчик, «Мы справимся!» и пробежка к пещере после отдыха.
- Сохранены рыцарь-рыбак, интервалы рыбалки и визитов торговца, ручная продажа, задания и автосохранение из v0.7. Сохраняется прежний ключ localStorage, предусмотрен перенос сохранений v0.7.

## Чего ПОКА нет — не выдавать за готовое

- Все шесть кадров каждой из трёх атак **не являются нарисованными отдельными спрайтами**: пока используется один герой с шестью наборами transform для рук/меча/корпуса. Это рабочая система сменного оружия, но не финальная художническая анимация.
- Сборный бездоспешный герой **не является пиксельно идентичным** оригинальному герою во всех шести позах. Оригинальный рисунок не перерисован; использована часть оригинала плюс дорисованное тело. Перед финальным выпуском нужна единая каноническая модель и коррекция точки хвата меча.
- Торговец и монстры сейчас 2D SVG-прототипы; часть движения сделана CSS-анимацией, а не индивидуальными покадровыми рисунками.
- Рыцарь-рыбак на утверждённой фоновой иллюстрации пока статичен; есть визуальные эффекты улова. Полноценной анимации рук и подсечки нет. Сцены и боевые слои нужно проверить на Android.
- SDK Яндекс Игр, реклама, сборка APK и приёмка производительности пока не выполнены. Это не релиз для публикации.

## Запуск с телефона Android

Сохрани ZIP в Downloads, затем в Termux:

```sh
termux-setup-storage
pkg install python unzip -y
mkdir -p ~/hrabrolap-v08
unzip -o ~/storage/downloads/hrabrolap-v0.8-preview.zip -d ~/hrabrolap-v08
cd ~/hrabrolap-v08
python -m http.server 8080 --bind 127.0.0.1
```

В Chrome открой **http://127.0.0.1:8080/**. Если на 8080 работает старый сервер, останови его в Termux (Ctrl+C). Не открывай `index.html` через `file://` — ES-модули браузера могут быть заблокированы.

## Проверить вручную

1. Открой инвентарь и магазин (две кнопки вверху). После накопления монет купи «Рыбий позвоночник», перейди в инвентарь и надень его. В бою должен быть только выбранный меч.
2. У Храбролапа не должен появляться «второй» встроенный меч ни на одной фазе атаки.
3. Бой автоматически меняет одну из трёх анимаций; враги атакуют разными способами.
4. При поражении котёнок отдыхает, дом показывает интерьер, затем называет «Мы справимся!» и идёт в пещеру.
5. На каждой 10-й волне корона; на 100-й завершается глава.
6. После покупки брони она появляется отдельным слоем. Покупка не лечит уже потерянное HP.
7. Рыба наполняет ведро, апгрейд до 24 срабатывает, а торговец принимает ручную продажу.
8. Закрой вкладку и открой снова — золото, экипировка и волны должны сохраняться.
