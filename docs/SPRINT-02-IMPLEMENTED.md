# «Храбролап» — Sprint 02 · Реальное внедрение анимаций героя, v0.9.1

**Статус:** рабочий технический риг, проверенная логика и мобильный предпросмотр. Художественная финальная приёмка пользователем не получена.

## Сделано, в игровом коде

- Созданы **18 новых независимых SVG-кадров**: `animations/hero/slash|overhead|thrust/01..06.svg`.
- Сохранена **исходная узнаваемая мордочка** Храбролапа, два глаза, шлем, цветок. Изменяются конечность с хватом, направление корпуса/головы, плащ и отдельные эффекты замаха. Полного разворота спиной нет.
- `game.mjs` теперь загружает нужный кадр `hero-body` при `heroFrame(index)` и поворачивает `weapon-slot` **вместе с** `hero-hand` одним и тем же SVG transform. Созданы единые данные атак в `hero-poses.mjs`; они используются и в игре, и в покадровом стенде.
- **Сменный меч не нарисован** ни в одном из 18 кадров тела. Купленный `iron`, `fishbone`, `moon` продолжает заменяться в `hero-weapon` без двойного клинка.
- Каждая из трёх атак имеет шесть кадров, на **четвёртом** происходит один видимый контакт; фактический урон по-прежнему начисляет `hero-hit` из игрового ядра, а не смена кадров. Шестой кадр совпадает со стойкой первого.
- Рубящий удар вдохновлён траекторией версии v0.7, но старые PNG кадры с нарисованным мечом **не используются** в бою и сохранены в архиве исходных материалов без изменений.
- У 12 кадров босса-слизня (6 атака + 6 урон) корона контрповорачивается на угол наклона тела. Она остаётся в той же вложенной группе, что и монстр, но видна **горизонтально**, включая прыжок и получение урона. У остальных семи видов положение короны этим спринтом не менялось.
- Предпросмотр `sprint-02-studio.html`: переключение трёх атак, шести кадров, трёх SVG-мечей, обычного и коронованного слизня.

## Проверки

- `npm test`: **27/27 PASS**, включая геометрическую проверку совпадения точки захвата руки и оружия, всех 18 кадров и выравнивания короны в 12 кадрах слизня.
- `npm run qa:balance`: **12/12 PASS**; показатели 100 волн не изменены.
- Chromium в контейнере, мобильные 390×844 и 320×700: `page.set_content` с исходными HTML, SVG и встроенными ресурсами, 0 JavaScript page errors, переключение кадра/меча работает, геометрия руки совпадает с мечом. Скриншоты `preview/hero-new-thrust-390.png` и `preview/hero-new-thrust-320.png`.
- **Ограничение:** разрешённый локальный HTTP и file:// заблокированы администратором браузерной среды (`ERR_BLOCKED_BY_ADMINISTRATOR`). Полный прогон игрового UI через обычную страницу на Android, FPS и устойчивость сохранений после reload **не проверены в этом спринте**. Проверен интерактивный студийный стенд, а не целый игровой цикл в браузере.

## Художественные ограничения

- Голова исходно представляет собой PNG, встроенный в SVG, а не отдельный чистый векторный рисунок. SVG оружия и базовые контуры тела — редактируемые. Новые кадры — технически пригодный последовательный риг, но не новый вручную нарисованный финальный набор.
- Можно доработать более естественную постановку локтя, бронеперчатки и эффектов удара перед окончательной публикацией в Яндекс Играх.
- В git пользовательского репозитория ничего не опубликовано этим спринтом. ZIP предназначен для продолжения работы с существующим проектом.
