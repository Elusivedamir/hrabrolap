# Рыбы, слизневая и костяная броня — QA 17.10.2026

## Изменения

Исправлены русские формы счётчика ведра, описания улова и продажи. Для пяти видов рыбы добавлены самостоятельные SVG-иллюстрации. Слизневый комплект стоит 15 слизи, костяной — 15 костей, без монет. Оба сохраняются как косметические костюмы с нулевым бонусом HP, по аналогии с двумя существующими. Рецепты с нулевой монетной ценой больше не исчезают из магазина. Недостаток материалов не списывает часть стоимости, повторная покупка не списывает материалы второй раз.

## Графика

Использован встроенный ImageGen. Edit target — прозрачный атлас 6×2 из утверждённых кадров «Золотого рыцаря». Общий промпт: менять только броню во всех двенадцати ячейках, сохранить котёнка, лицо, цветок, красный платок, хвост, позы и эффекты; первый ряд attack, второй hurt; прозрачный фон, включая промежутки между лапами; без пола, платформ, теней на земле, надписей и оружия. Вариант slime: облегающие зелёные гелевые пластины с пузырьками и застёжкой-каплей. Вариант bone: тёплые костяные пластины и рёбра поверх коричневой кожи, сегментированные наручи и поножи; дружелюбный стиль без шлема.

Сгенерированы два атласа. Техническая нарезка — равномерная сетка 6×2 и приведение всей ячейки к размеру 279×370, без индивидуального обрезания по контуру и без программного удаления фона. RGBA сохранён. Все 24 кадра просмотрены на контрастном фоне, белой платформы нет. Исходные ранее утверждённые изображения не менялись. Новые рисунки требуют художественной приёмки пользователя.
