# Переход на прозрачные спрайты, 17.10.2026

Оригинальные PNG в `assets/canonical/` и `assets/costumes/forest_guardian/`, `assets/costumes/steel_knight/` неизменны. Их прозрачные игровые копии находятся в `assets/clean/`, подготовлены Python/Pillow без ручного удаления белых элементов мордочки и лап. Применяется ограниченная заливка внешнего фона плюс удаление тени исключительно ниже последнего тёмного контура каждой колонки.

Доступные комплекты: только «Лесной страж» и «Золотой рыцарь», по 50 монет. Четыре ранее автоматически собранных комплекта удалены из действующих ресурсов игры. Старые невостребованные SVG-эскизы брони в art/armor/ остаются как рабочие исходники, не появляются в магазине.

Надпись с подсказкой и скоростью ударов под котёнком скрыта CSS. Переключатель автобоя сохранён, но без числовой скорости. Все SVG-мечи остаются отдельными; длина клинка увеличена с 1.6 до 2.0 без изменения рукояти.

Регрессионные проверки: `npm test`, `npm run qa:balance`, `npm run qa:browser`. Художественная оценка остаётся отдельной от технической.
