## Что смотреть

Запусти `p1-review.html` из этой ветки в локальном сервере Android/Chromium: можно скрыть героев, выбрать R001 / R005 / R012, поставить анимацию на паузу и перебрать 6+6 кадров. Героем в просмотрщике отображается **неизменённый** канонический PNG `assets/canonical/attack_01.png` — это только ориентир масштаба.

### Команда на Android без переключения рабочего main

```bash
cd ~/hrabrolap-new
git fetch origin feature/p1-art-prototypes
git worktree add ~/hrabrolap-p1 FETCH_HEAD
cd ~/hrabrolap-p1
python -m http.server 8091 --bind 127.0.0.1
```

Адрес: `http://127.0.0.1:8091/p1-review.html`.

**Важно:** разные порты имеют разные `localStorage`, но просмотрщик не загружает и не пишет игровые сохранения. Порт 8090 с основной игрой остаётся отдельным.
